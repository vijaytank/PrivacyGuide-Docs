# Contributing to Privacy Guide

Thank you for your interest in Privacy Guide! We welcome contributions that help improve our documentation, refine our risk heuristics, or expand our educational content.

## How to Contribute

1.  **Report a Bug**: If you find a bug, please use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md).
2.  **Suggest a Feature**: If you have an idea for a new feature, please use the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md). 
3.  **Submit a Documentation Update**: This repository (`PrivacyGuide-Docs`) is for public-facing documentation. If you've found a typo or want to improve a guide, please open a **Pull Request**.

## Contribution Guidelines

- **Privacy First**: Never include any sensitive personal information, device IDs, or specific app lists in your pull requests or issues.
- **Maintain Clarity**: Keep our guides simple and easy to understand for everyday users.
- **Respect the Scope**: Our mission is transparency, education, and control over Android permissions. Contributions that deviate from this scope (e.g., system-level overrides or intrusive tracking) will not be accepted.

## Security Reports

Please do **NOT** report security vulnerabilities via GitHub Issues. See our [Security Policy](SECURITY.md) for private reporting instructions.
