# Security Policy - Privacy Guide

## Supported Versions

Our team is dedicated to addressing security vulnerabilities in a timely manner. We currently support the following versions of Privacy Guide:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Privacy Guide, please do **NOT** open a public issue. Instead, report it privately to:
📧 [vijaytank132@gmail.com](mailto:vijaytank132@gmail.com)

Please provide the following details in your report:
- A clear description of the vulnerability.
- Steps to reproduce the issue (if applicable).
- Your assessment of the impact (low, medium, high, critical).

We will acknowledge receipt of your report within **48 hours** and work to resolve the issue as quickly as possible.

## Security Posture

- **No Online Sync**: Privacy Guide is designed to be an offline-first tool. It does not sync data to any cloud service, minimizing the risk of data breaches.
- **Permission Mapping**: The app only uses the minimum required permissions to function. The `QUERY_ALL_PACKAGES` permission is used solely for the on-device audit and is never transmitted.
- **Open Documentation**: We maintain this public documentation repository to ensure transparency about our data practices and security measures.
